# 🌐 GlyenStudio

**GlyenStudio** is a modern web platform that showcases and sells high-quality website templates. Each template is beautifully designed, affordably priced, and instantly delivered to buyers after successful Paystack payment.

---

## 🚀 Features

- 💻 **Responsive Design** – Works seamlessly on desktop, tablet, and mobile.  
- 🛒 **Template Marketplace** – Explore professionally designed templates with live previews and prices.  
- 💳 **Inline Paystack Integration** – Secure, fast, and user-friendly payment gateway.  
- 📁 **Instant Delivery** – After payment, the purchased template is automatically delivered via Google Drive.  
- 📞 **Contact & About Pages** – Includes essential pages for communication and brand identity.  
- ⚡ **Fast & Lightweight** – Built for performance and smooth user experience.

## 💰 Payment Flow

1. User selects a website template.  
2. Clicks the **Buy Now** button.  
3. Paystack inline form opens for secure payment.  
4. On successful payment, a Google Drive link to the purchased template is sent to the buyer’s email.
